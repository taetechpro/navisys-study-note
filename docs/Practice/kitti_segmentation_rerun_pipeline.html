LiDAR-only 경로 · 카메라/IMU 는 메인 루프에서 병렬로 돌지만 segmentation 입력에 일절 안 들어감
📌 이 문서의 범위
LidarSegmenter::process 의 입력은 std::vector<LidarPoint> 하나뿐이다 — 카메라 이미지, EKF 자세, IMU 모두 받지 않는다. 즉 segmentation 은 순수 기하 기반 LiDAR-only 처리이며, 본 문서는 그 경로(.bin → RANSAC → Rerun)만 다룬다. 카메라+IMU 트랙(StereoTracker, LcEkf)은 동일 메인 루프에서 병렬·독립으로 돌아 같은 Rerun timeline 에 합쳐질 뿐이다.

3. Stage 2 — KittiRawReader · path/timestamp 로딩

CLASS KittiRawReader::load_velodyne()

KittiRawReader 는 카메라·IMU·LiDAR 모두 로드하지만, 본 문서에서는 LiDAR 부분만 관심.

입력

  • dataset_root (string)

관심 출력

  • lidar_data() → std::vector<std::string> (.bin 파일 경로 list)

실제 점군은 이 시점엔 안 읽음 (lazy). 메인 루프에서 frame 마다 lidar_data[frame_count] 로 경로만 꺼낸 뒤 load_kitti_velodyne_bin 으로 그때그때 읽는다.

4. Stage 3 — 메인 루프 (run_vio.cpp)

FUNC 메인 루프 — LiDAR 분기만 발췌

// run_vio.cpp:912-954  ── LiDAR 관련 부분만 추출
for (int frame_count = 0; frame_count < camera_data.size(); ++frame_count) {

    // ┌── 카메라/EKF 트랙 (생략) — 본 흐름의 입력이 아님 ─┐
    // │  tracker.process(img_l, img_r);                  │
    // │  ekf.update(pose);                               │
    // │  rerun.log_frame(...);                           │
    // └──────────────────────────────────────────────────┘

    // ── LiDAR 트랙 (관심 대상) ─────────────────────────
    if (cli.segment_lidar && frame_count % cli.segment_every == 0) {
        const auto lidar_points = load_kitti_velodyne_bin(lidar_data[frame_count]);
        const auto segmented    = lidar_segmenter.process(lidar_points);
        rerun.log_lidar_segments(frame_count, cam.timestamp, segmented);
        if (write_lidar_ply) write_segmented_ply(...);
    }
}

핵심:

  • frame index 만 카메라와 공유 — lidar_data[frame_count] 로 같은 시각의 .bin 선택.
  • 그 외 카메라/EKF 의 어떤 결과도 lidar_segmenter.process() 에 안 들어감.
  • Rerun timestamp 는 cam.timestamp 사용 — 시각 축 통일을 위함이지 데이터 융합이 아님.

5. Stage 4 — Velodyne .bin 로드

FUNC load_kitti_velodyne_bin(path) → vector<LidarPoint>

파일 포맷처리
binary, float[4] × N (x, y, z, intensity)한 점 = 16 byte
파일 크기 % 16 ≠ 0잘림 → 예외
좌표계+x 전방, +y 좌측, +z 상방

속도: 한 프레임 ~120,000 점 → 약 2 MB → SSD 에서 1ms 이하.

7. Stage 6 — Rerun 시각화

SINK rerun::log_lidar_segments(frame_idx, timestamp, cloud)

SegmentedCloud 를 받아 Rerun 에 세 종류 로그를 동시에 기록:

Rerun entity타입내용
/lidar/segmentsPoints3D색상 입힌 3D 점군 (반지름 0.035 m)
/metrics/lidar_floor_pointsScalarsfloor 라벨 점 개수 (timeline)
/metrics/lidar_left_wall_pointsScalars좌측 벽 점 개수
/metrics/lidar_right_wall_pointsScalars우측 벽 점 개수
/metrics/lidar_front_wall_pointsScalars전방 벽 점 개수

Rerun 의 timeline 은 set_time_duration_secs("time", relative_time(timestamp)) 로 카메라·EKF 로그와 동일 시각축. 즉 한 시점을 클릭하면 카메라 이미지·feature·plane segmentation·메트릭이 동시에 보임.

Rerun 미사용 시: write_segmented_ply() 가 output/lidar_segments/<frame_id>.ply 로 저장 → CloudCompare / MeshLab 에서 라벨별 색상 그대로 확인.
